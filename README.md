# PC Browser

متصفح أندرويد بيفتح أي موقع على إنه كمبيوتر (Windows / Chrome)، وفيه تحكم على الشاشة:

| الجزء | الوظيفة |
|---|---|
| جويستيك شمال | حركة `W A S D` |
| جويستيك يمين | تحريك الماوس (مؤشر على الصفحة) |
| `Shift` / `Alt` / `Q` | فوق الجويستيك الشمال |
| `F` / `V` / `MMB` (زرار نص الماوس) | فوق الجويستيك اليمين |
| `LMB` / `RMB` | كليك يمين وشمال للماوس (إضافة مني عشان المؤشر يقدر يضغط) |
| زرار 🎮 فوق | إظهار / إخفاء التحكم |

زرار الرجوع في الموبايل: لو اللعبة حاطة قفل للماوس (Pointer Lock) بيفك القفل الأول، وبعدها يرجع للصفحة اللي قبلها.

## بناء الـ APK

### الطريقة 1: GitHub Actions (من غير ما تنزّل حاجة)
1. اعمل Repository جديد على GitHub وارفع عليه محتويات المجلد ده كلها (بما فيها `.github`).
2. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
3. بعد دقيقتين تلاتة نزّل الملف من **Artifacts** باسم `PCBrowser-apk` (جواه `app-debug.apk`).

### الطريقة 2: Android Studio
افتح المجلد، استنى الـ Sync، وبعدين **Build > Build APK(s)**.
الملف بيطلع في `app/build/outputs/apk/debug/app-debug.apk`.

للتثبيت لازم تسمح بـ "التثبيت من مصادر غير معروفة" في الموبايل.
